# Code Review

아래 경로는 프로젝트 루트 기준이다. 이 Skill이 있는 `.claude/skills/code-review/`에서 세 단계 위가 프로젝트 루트이다.

`.ai/workflows/code-review.md`를 실제로 읽고 순서대로 수행한다. 읽을 규칙 문서는 Workflow 첫 문단이 정한다. 그 목록을 여기에 복제하지 않는다.

`.ai/rules/ai-collaboration.md`는 `CLAUDE.md`가 세션 시작 때 이미 불러온다. 이 세션에서 아직 읽지 않았을 때만 읽는다.

참조 문서가 없거나 읽을 수 없으면 임의의 절차로 대체하지 말고 누락을 보고한다.
