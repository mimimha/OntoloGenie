# Implement

이 Skill이 있는 `.claude/skills/implement/`에서 세 단계 위가 프로젝트 루트이다. 아래 경로는 현재 작업 디렉터리나 Skill 디렉터리가 아닌 **프로젝트 루트 기준**이다.

작업 전에 다음 공통 문서를 실제로 읽는다.

- `.ai/rules/ai-collaboration.md`
- `.ai/rules/code.md`
- `.ai/rules/architecture.md`
- `.ai/rules/testing.md`
- `.ai/references.md`
- `.ai/workflows/implement.md`

읽은 Workflow를 순서대로 수행하고, Workflow가 조건에 따라 지정한 규칙 문서도 실제로 읽는다. 공통 권한 기준과 결과 보고 형식을 적용한다. 참조 문서가 없거나 읽을 수 없으면 임의의 절차로 대체하지 말고 누락을 보고한다. 규칙과 상세 절차의 원본은 `.ai/`이며 이 Skill에 복제하지 않는다.
