# 후속 연동·검증 목록

작업 중 API·데이터가 준비됐는지 확인하고, 검증한 항목만 완료로 바꾼다. 화면 구현·모의 테스트 통과를 실제 서버 연동 완료로 취급하지 않는다.

| 이슈             | 남은 항목                                                                  | 다시 확인할 조건                                                 |
| ---------------- | -------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| 110              | 실제 제안의 상세·근거·신뢰도·필터·페이지 이동                              | 서버에 실제 제안 및 페이지 이동할 만큼의 데이터 등록             |
| 111              | 실제 관계·속성으로 저장, 개정 증가·검사 요청·변환 순서 보존                | 실제 관계·속성과 검사용 제안 준비                                |
| 112              | 서버 후보 비교, 선택·보류 저장, 후보별 검사 결과                           | 실제 복수 후보 등록, 선택·보류 API 및 후보별 검사 연결 계약 제공 |
| 113              | 수동 검사 실행·중복 요청·충돌·상태 전용 API 연결, 실제 서버 집계·표본 조회 | API 059~061 제공, 서버에 해당 제안 개정의 완료된 검사 결과 생성  |
| 54               | Jenkins 실제 자동 배포·롤백의 미검증 부분                                  | 다음 관련 백엔드 배포 및 합의된 롤백 검증 시점                   |
| Credentials 전환 | 원천 접속 정보 암호화·복호화·접속 검증                                     | 실제 원천 등록 데이터 및 검사용 접속 환경 준비                   |

## 확인된 진행 상태

- 104 역할별 접근·226 계정 관리는 사용자 서버 검증 완료.
- 112 비교 화면 첫 MR 병합, 자동 테스트·사용자 로컬 검증 완료. 서버 목록 0건으로 상세 검증은 보류.
- 113 결과 조회 API 062는 코드에 존재한다. 실행 API 059~061은 현재 브랜치에서 확인되지 않았다. 새 API가 들어오면 이 판단부터 갱신한다.
- 227은 사용자 결정으로 범위 제외·Jira 삭제, 초안 삭제 완료.

이 목록은 배경 감시나 자동 알림을 설정한 것이 아니다. 후속 작업 시 확인하는 체크리스트다.
