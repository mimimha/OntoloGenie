# S15P31C106-225 원천 표본 화면

데이터 연결 → 원천 선택 → 원천 표본 탭 (`/admin/sources?source={id}&tab=samples`).
읽기 가능한 TABLE 선택, 행 수 1~20(기본 20), 요청 접수·대기·실행·실패·성공,
빈 결과, 만료·404, 기존 요청 합류, 표시 값·가림·미제공 상태를 구현한다.

## 현재 연결 범위

- 기존 014 자원 목록만 호출한다. 운영에 표본 조회 어댑터는 주입하지 않는다.
- `samplePreview.ts`는 화면 전용 모델이며 서버 DTO나 확정 가림 정책이 아니다.
- 016·102 실제 요청 함수/Mock HTTP 계약을 임의로 만들지 않는다. 테스트는 합성 데이터와 주입한 함수로 화면 흐름을 검증한다.
- 표본은 컴포넌트 수명 동안만 보관하며 React Query 캐시·브라우저 저장소에 넣지 않는다. 대상 전환·만료 시 제거한다. 원천 오류 원문은 표시하지 않는다.
- 가림 셀에는 원문을 전달하지 않는다. 화면에서 컬럼명으로 민감도를 추정하거나 가림 규칙을 정하지 않는다.

5. 원천 금지 컬럼이 응답·DOM·오류에 나오지 않는지 운영 검증하고 팀원 리뷰·병합 후 Jira 완료 기준을 확인한다.
