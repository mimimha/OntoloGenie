## 제약과 해석

- CSRF 오류는 테스트 선행 데이터를 만들기 위한 객체 유형 생성 API(022)의 Swagger 요청에서 발생했다. 228 매핑 저장 API가 실패했다고 해석하지 않는다.
- 프론트의 공통 API 클라이언트는 CSRF 헤더를 전달하지만, 객체 유형 생성 UI는 현재 매핑 화면에 없다. Swagger 요청을 정상 인증·CSRF 경로로 실행할 수 있는 담당자가 선행 데이터를 준비해야 한다.
- 로그인 정보를 읽거나 바꾸지 않았고, 계정 역할·권한을 변경하지 않았다. 신규 객체 유형·속성·매핑도 생성되지 않았다.
- 코드·자동 테스트에서 확인한 기본 API 연결 여부와 실제 운영의 등록·수정 성공은 구분한다. 현재 기록만으로 228 전체 완료를 판단하지 않는다.

## 재개 조건

1. 검증용 객체 유형 QA_228_20261108 및 STRING 속성 1개 이상을 정상 API 경로로 준비한다. 이후 객체 매핑은 비활성으로 등록해 업무 수집과 구분한다.
2. 기존 viewer 계정의 소유자가 정상 로그인 정보를 확인하거나 담당자가 정식 복구 절차로 로그인 가능 상태를 준비한다. 비밀번호는 채팅에 전달하지 않는다.
3. 준비 후 프론트에서 객체·속성 매핑 등록·수정·재조회, 동일 속성 중복 409, 두 탭의 오래된 rowVersion 충돌 및 비관리자 API 차단을 검증한다.
