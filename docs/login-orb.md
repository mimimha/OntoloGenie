# 로그인 오브

사용자가 제공한 VoicePoweredOrb의 보라·시안 GLSL 셰이더를 로그인 소개 영역에 적용한다. 마스코트 구성과 파일은 보관하며 로그인에서는 사용하지 않는다.

- 구현: `frontend/src/components/ui/voice-powered-orb.tsx`
- 원본 셰이더: `frontend/src/components/ui/voice-powered-orb-shaders.ts`
- 오브 스타일: `frontend/src/components/ui/voice-powered-orb.css`
- 배치: `frontend/src/features/auth/LoginPage.tsx`, `login.css`
- 의존성: `ogl`. 로그인 폼은 기존 Button과 스타일을 사용하므로 제공된 데모의 Radix·CVA 버튼은 추가하지 않는다.

## 동작

기본적으로 빛이 흐르고 포인터를 올리면 표면이 반응한다. 데스크톱에서는 왼쪽에 배경과 소개 문구 없이 오브만 배치한다. 오른쪽 로그인 폼은 로고·제목·필드·버튼으로 구성하며 WELCOME 문구와 설명을 표시하지 않는다. Pretendard 웹폰트와 디자인 시스템의 heading-32, label-14, input-14, control-14를 사용하고, 입력·버튼은 높이 40px와 모서리 4px, 주요 버튼은 brand-strong을 따른다. 오브 최대 너비는 데스크톱 420px, 960px 이하 260px, 480px 이하 180px이며, 960px 이하에서는 로그인 폼 위에 배치한다. 오브는 정사각형 비율을 유지하고 ResizeObserver로 컨테이너 크기를 따라간다. 픽셀 밀도는 최대 2배이며, OGL에 논리 크기를 전달해 중복 확대를 피한다.

로그인 페이지의 `enableVoiceControl`은 false이므로 마이크 권한을 요청하지 않는다. 음성 반응이 필요한 별도 사용처에서는 명시적인 사용자 동작으로 이 속성을 켠다. 마이크 스트림은 제거 시 종료하며, 제거 후 늦게 승인된 스트림도 즉시 종료한다. 분석한 음성은 서버로 전송하지 않는다.

화면 밖과 숨긴 탭에서는 애니메이션을 멈춘다. 동작 줄이기 설정에서는 정지 프레임을 표시한다. WebGL 미지원이나 컨텍스트 손실 시에는 CSS 오브로 대체한다.

클릭·터치한 지점을 반동과 파동의 공통 중심으로 사용하며 150ms 동안 오브를 0.93배로 살짝 당겼다가 즉시 놓는다. 캔버스의 실제 표시 영역으로 입력 좌표를 환산하므로 화면 크기와 픽셀 밀도가 달라도 클릭한 위치를 유지한다. 이후 감쇠 진동 곡선을 따라 빠르게 커지고 작아지는 반동이 점차 잦아들며 총 1300ms에 원래 크기로 돌아온다. 클릭 시 전체 윤곽을 크게 변형하는 대신 호버 파형을 더 촘촘한 잔물결로 전환한다. 클릭 좌표를 셰이더 좌표로 환산하고 오브 회전에도 같은 좌표계를 적용한다. 클릭 지점에서 시작한 세부 파형이 시간에 따라 원형 띠로 바깥으로 이동한다. 이동하는 띠에만 세부 파형을 혼합하고, 지나간 영역은 기존 파형으로 돌아온다. 거리가 멀어질수록 세부 주파수는 22에서 12로 낮아지고 강도도 약해져 점점 느슨해진다. 세부 진폭은 호버보다 낮게 유지해 전체 형태가 찌그러지는 느낌을 줄인다. 80ms 안에 세부 파형이 올라오고 2.4초 동안 퍼진 뒤 평소 흐름으로 돌아온다. 색상과 평소 호버 움직임은 유지하며 재클릭 시 다시 시작한다. 오브의 캔버스만 변형하므로 파동은 반동에 끌려가지 않고 클릭 지점을 중심으로 독립적으로 바깥으로 퍼진다. 클릭 즉시 해당 좌표에 지름 8px의 작은 원이 나타나며, 첫 보라색 파동이 2600ms 동안 천천히 바깥으로 커진다. 두 번째 파동은 같은 위치에서 320ms 뒤에 출발하며 2900ms 동안 더 넓고 희미하게 따라간다. 두 원은 별도 요소로 재생해 일정한 시간차를 유지한다. 파동은 반지름이 약 1~3% 불규칙한 SVG 경로를 사용한다. 같은 점 수의 경로들을 부드럽게 보간해 둘레가 살짝 출렁이며, 두 파동은 서로 다른 형태로 움직인다. 둘레에는 보라·파랑·시안 그라데이션과 구간별 밝기 차이를 주어 빛이 부분적으로 풀리도록 한다. 그라데이션 색상은 재생 중에만 천천히 바뀌며 두 번째 파동은 반대 순서로 색이 흐른다. 색상 애니메이션은 파동이 재생되는 동안만 실행하고 종료·취소 시 함께 정리한다. 초기 지연이나 이미 커진 원으로 시작하지 않아 발생 지점이 분명히 보인다. 최대 배율은 파동의 3.2배이며 화면 양쪽 여유에 맞게 줄여 가로 넘침을 막는다. 초반에는 파동을 선명하게 유지하고 큰 원으로 퍼진 뒤 투명도가 부드럽게 0으로 수렴한다. 끝으로 갈수록 살짝 흐려져 자연스럽게 사라진다. 연속 입력은 이전 효과를 취소하고 새 클릭 지점에서 다시 시작한다. 크기가 바뀌면 효과를 취소하고, 파동이 끝나면 위치 스타일을 초기화해 반응형 전환 시 가로 넘침을 막는다. 화면이 숨겨지거나 동작 줄이기를 켜면 클릭 효과도 취소하고, 컴포넌트 제거 시 애니메이션 자원을 정리한다.

호버로 변형된 빛이 캔버스 경계에서 잘리지 않도록 렌더링 영역을 레이아웃 크기의 1.25배로 확장한다. 셰이더 좌표에도 같은 배율을 적용해 오브 자체의 크기와 픽셀 밀도를 유지하며, 부모의 페인트 클리핑을 사용하지 않는다.

## 검증

로그인 기존 동작, 렌더러와 마이크 자원 정리, 고밀도 화면 크기, 동작 줄이기를 자동 테스트로 확인한다. 브라우저에서는 실제 셰이더 렌더링·시간 변화·포인터 반응과 320~1440px 배치를 확인한다.
